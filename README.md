# Інтелектуальна система автоматизованої інспекції фасадів будівель на основі аналізу зображень з БПЛА
---

## 🎯 Про проєкт
Метою даного проєкту є створення програмно-апаратного комплексу для автоматизації інспекції інфраструктурних об'єктів. Система використовує фотографії, зроблені з безпілотних літальних апаратів (БПЛА), для розпізнавання та класифікації дефектів (тріщин, відшарувань тощо) за допомогою нейронних мереж, з подальшим перенесенням знайдених пошкоджень на 3D-модель будівлі.
